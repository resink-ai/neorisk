# etherscan

address history (normal, internal, ERC-20) from Etherscan V2; needs ETHERSCAN_API_KEY.

```sh
uv run eth-collect etherscan --help
uv run eth-collect etherscan --limit 10   # quick check
```

Source details, field mapping and known quirks: `.claude/skills/eth-collect/references/etherscan.md`.
